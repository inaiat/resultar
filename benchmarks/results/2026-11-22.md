# Resultar benchmark results · 2026-11-22

All 12 distinct suites in the benchmark workspace ran sequentially on an Apple M4 (arm64), macOS 27.2.1, Node.js 26.13.1. The local build used the `v5` branch working tree based on `8cd6a0c`, before the first beta version bump. The published baseline was the npm tarball for `resultar@4.1.1`. JIT on/off refers to the Resultar setting. V8 retained its defaults. Each suite kept its own warmup and sampling methodology.

Run a suite with `pnpm --filter resultar-benchmarks run bench:<name>`. The names below match the scripts. For `stable`, use the settings below. For `effect`, `neverthrow`, `task`, and `function`, each JIT mode ran in a separate process. The other JIT comparisons use the modes implemented by each suite.

The comparisons below use separate results for Resultar JIT on and off. Against published v4.1.1, the v5 build measured +23.5% / +30.4% for an immediate success in `runPromise()`, +124.7% / +127.4% for an immediate success in `runResult()`, and +6.4% / +5.6% when migrating five successful items from `ResultAsync.combine` to `ResultTask.all`. The paired percentages are JIT on / off.

## stable · v5 versus published 4.1.1

Three processes per JIT mode in order 1, 0, 0, 1, 1, 0. Each ran nine alternating rounds for each of 36 scenarios, with 400,000 synchronous or 30,000 asynchronous operations per round.
```sh
for jit in 1 0 0 1 1 0; do

    BENCH_SYNC_ITERATIONS=400000 BENCH_ASYNC_ITERATIONS=30000 pnpm run bench:stable
done
```
